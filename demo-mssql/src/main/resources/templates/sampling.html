平均抽幾片
Chamber ID 以逗號隔開. 請注意全半形視為不同字.

抽檢 Sheet 方式三選一

1. CHAMBER Type

- 指定 CH : 指定哪些 Chamber ID 的 Sheet 進行抽檢
- 平均分配 : 平均每一個 Chamber 抽幾片 (不指定 CH)

2. 只抽檢 Process Sheet

- Yes : 卡匣中在此 EQP 之 process sheet 才進行抽檢

3. 手動指定 Slot

- 有手動指定 : 可設定 抽定 OP 抽檢 Slot
- 不手動指定 : 上述方式都不使用時, 以機台本身設定而抽檢
